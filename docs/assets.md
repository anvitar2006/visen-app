# Asset provenance

## Lifestyle photograph

`public/images/ritual.jpg` is the unmodified notebook, plant, pencil, glasses, and laptop photograph distributed as `src/assets/img/home-bg.jpg` in Start Bootstrap's Clean Blog repository.

- Source pinned to commit `1ebc4f8f3b6194335df237a2a7837955a5a4a9aa`: https://github.com/StartBootstrap/startbootstrap-clean-blog/blob/1ebc4f8f3b6194335df237a2a7837955a5a4a9aa/src/assets/img/home-bg.jpg
- Distribution license: MIT, copyright 2013–2023 Start Bootstrap LLC. Full source notice is preserved in `public/licenses/ritual-source.txt`.
- The bundled photograph and license were compared byte-for-byte against the pinned source. No original photographer identity is inferred. This is not commissioned Visen photography and is not AI-generated.
- The file is unchanged. The interface uses a restrained CSS warmth/saturation treatment and responsive cropping.

The previous mountain photograph and its unused source notice were removed from the current distribution. No images are requested from external providers at runtime.
